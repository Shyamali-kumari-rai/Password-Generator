# Password Generator

A responsive password generator built with React, Tailwind CSS, and Vite.

## Features
- **Customizable Length**: Adjust password length with a real-time slider.
- **Character Options**: Toggle numbers and special characters.
- **Copy to Clipboard**: One-click copy functionality with input selection feedback.
- **Auto Generate**: Regenerates passwords automatically as options change using React hooks (`useCallback`, `useEffect`, `useRef`).

## Tech Stack
- [React](https://react.dev/)
- [Vite](https://vitejs.dev/)
- [Tailwind CSS](https://tailwindcss.com/)

## Getting Started

### 1. Install Dependencies
```bash
npm install
```

### 2. Start Development Server
```bash
npm run dev
```

### 3. Build for Production
```bash
npm run build
```
